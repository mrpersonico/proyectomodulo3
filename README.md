# 📚 Proyecto Módulo 3: Aplicación de Consola en JavaScript

Este proyecto es una aplicación interactiva desarrollada en JavaScript que se ejecuta en la consola del navegador web. Diseñada como un sistema de gestión para una plataforma de aprendizaje interactivo, permite interactuar con un catálogo de cursos, realizar operaciones matemáticas, filtrar datos y manipular estructuras de objetos y arreglos.

---

## 🚀 Funcionalidades Principales

- **Menú Interactivo**: Interfaz guiada por `prompt()` y `alert()` dentro de un bucle `while` controlado por sentencias `switch`.
- **Catálogo de Cursos**: Gestión de un listado de cursos utilizando arreglos de objetos.
- **Filtrado Dinámico**: Búsqueda y filtrado de cursos por presupuesto máximo mediante el método `.filter()`.
- **Cálculo de Promedios**: Implementación de funciones puras y el método `.reduce()` para calcular el costo promedio de la oferta académica.
- **Inserción de Datos**: Registro de nuevos cursos con validaciones de entrada para asegurar precios numéricos y nombres válidos.

---

## 🛠️ Conceptos de JavaScript Aplicados

1. **Variables y Operadores**: Uso de `let` y `const` para la declaración de variables y ámbito.
2. **Estructuras de Control**: Uso de `if / else`, `switch` y bucles `while`.
3. **Funciones y Modularización**: Funciones flecha (`=>`) y declarativas reutilizables para mantener un código limpio y legible.
4. **Arreglos y Objetos**: Manipulación avanzada con métodos de iteración como `.forEach()`, `.map()`, `.filter()` y `.reduce()`.
5. **Validación de Entradas**: Verificación de datos con `isNaN()`, `parseFloat()` y `trim()`.
